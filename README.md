# Домашнее задание: «Легендарная команда»

Реализация объектно-ориентированной логики для текстовой RPG-игры.

## Что сделано в проекте:
1. **Новый герой**: Добавлен класс `Paladin`, наследующий `Hero`. Реализован уникальный метод `special()`, который лечит паладина и временно увеличивает его атаку.
2. **Новый предмет**: Создан класс `Item`. Предмет «Светоносный Меч» дает `+15` к атаке, хранится в списке `inventory` героя и может быть активирован.
3. **Бой с боссом**: В файле `main.py` настроен пошаговый цикл сражения с `Boss` (Драконом). Игра гарантированно завершается победой одной из сторон.
4. **Git**: Проект успешно закоммичен в ветке `feature-new-hero` и объединен с веткой `main`.

## Инструкция по запуску:
1. Установите Python (версии 3.x).
2. Запустите игру через терминал командой:
   ```bash
   python main.py
   ```
